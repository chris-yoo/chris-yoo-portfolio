동역학 방정식 기반 Sim-to-Real 파라미터 타겟팅

Sim-to-Real Gap의 원인 중 하나: 동역학 파라미터의 불확실성

M(q)q̈ + C(q, q̇)q̇ + g(q) + τfric = τ

M(q)관성 행렬 (Inertia Matrix) ➔ Armature 관성, 링크/손목 질량
C(q, q̇)코리올리 및 원심력 ➔ (관성/질량에 종속됨)
g(q)중력 벡터 (Gravity) ➔ 링크/손목 질량
τfric마찰력 (Friction) ➔ 관절 쿨롱/점성 마찰
τ모터 제어 토크 (Motor Torque)

이 중 무엇이 성공률을 가장 많이 떨어뜨리는가?

실험 - 환경

실제 로봇에서는 단일 물리 파라미터의 변인 통제·계측이 어려움
➔ 시뮬레이션을 통제된 실험실로 활용하도록 환경을 구성

로봇  Franka Emika Panda (7-DoF) + 2지 평행 그리퍼

태스크  Peg-in-Hole (반경 공차 0.057 mm)

시뮬레이터  Isaac Sim / Isaac Lab, Factory PegInsert 환경

제어·관측  태스크 공간 임피던스 제어, 비전 센서 없이 로봇 및 환경의 State 벡터만 활용

학습  PPO 알고리즘 적용, 네트워크 구조: MLP [512, 128, 64] + LSTM 1024
200 Epoch 학습 결과 ➔ 기본 환경(Base) 성공률 99.5 % 달성

· Input  EE와 hole의 상대위치, EE의 자세, EE의 선속도·각속도, 직전 스텝의 action

· Output  태스크 공간 내 목표 EE 위치 및 자세

결론 및 제언

결론: Peg-in-Hole 태스크 수행 시 갭의 주요 원인은 관절 쿨롱 마찰

—정렬을 위한 미세한 구동 토크: 궤적이 매우 작고 정밀하여 가속도가 낮기 때문에, 실제로 로봇을 움직이기 위해 추가로 계산되는 구동 토크 성분은 매우 작음
—준정적 상태에서의 쿨롱 마찰력: 삽입 마지막 단계는 가속도와 속도가 0에 수렴하는 준정적 상태. 속도와 무관하게 항상 일정한 쿨롱 마찰만이 정렬을 방해하는 가장 큰 저항
—물리적 데드밴드 발생: 목표 위치로 이동하기 위해 계산된 미세한 구동 토크가 관절의 쿨롱 마찰력을 이기지 못해 로봇이 움직이지 못하는 구간이 발생, 이것이 최종 태스크 실패로 직결

다음 단계 (Next Steps)

—학습 시 관절 마찰값을 무작위로 변화시키는 Domain Randomization을 적용해 재학습하고,
동역학이 변형된 로봇에서도 성공률이 회복되는지 확인
—실제 환경에서 해당 정책이 유효한지 실로봇을 통한 검증
