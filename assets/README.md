# 포트폴리오 시각자료 넣는 곳

슬라이드 번호별 폴더입니다. 해당 폴더에 파일을 넣어주시면 제가 슬라이드에 배치하겠습니다.

**파일 이름은 아무렇게나 지으셔도 됩니다.** 다만 한 폴더에 여러 장을 넣으실 때는 `01-`, `02-` 처럼 앞에 번호를 붙여 순서를 알려주시면 좋습니다.

**형식** PNG · JPG · PDF 모두 가능합니다. 화면 캡처는 가능하면 원본 해상도로 넣어주세요. 인쇄 시 흐려지지 않습니다.

**없는 자료는 비워두셔도 됩니다.** 빈 폴더는 그림 없이 글과 도식으로만 구성하겠습니다.

## 폴더별 필요 자료

### `02-heir-team/` — HEIR 팀 소개와 문제 정의
- 한양대학교 박물관 파트너십 관련 사진 또는 협약 장면
- 팀 사진
- 수장고에 유물이 쌓여 있는 사진 *(문제를 한 장으로 보여주는 데 가장 효과적)*

### `03-bonda-features/` — Bonda 기능 ★필수
- 검색 결과 화면
- 지도(GIS) 화면
- 이미지·도면 검색 화면
- 고고학 사전 화면
- 학예사·연구실 인터뷰 현장 사진 *(있으면 신뢰도 크게 상승)*

### `04-bonda-workshop/` — Bonda 확산 ★필수
- **학예사 약 50명 대상 워크숍 발표 사진** ← 이 포트폴리오에서 가장 강한 한 장
- 발표 자료 표지 또는 시연 장면

### `05-heirloom/` — 유물 관리 시스템 ★필수
- 유물 등록 화면
- 목록 화면
- 상세 화면
- **이미지 자동 전처리 전후 비교** (원본 → 영역 분리·빛번짐 보정 결과) ← 효과가 가장 큰 자료
- 스케일바 기반 크기 측정 예시
- 학예사 미팅 사진

### `06-exhibition/` — HEIR Exhibition ★필수
- 프로토타입 시연 화면 (스캔 → 복원 → 3D 체험 흐름)
- 깨진 도자기 → 완형 3D 복원 전후 비교
- 3D reconstruction 결과물 (사진 15장 입력 → 3D 자산)
- 일대기 영상 캡처

### `07-aidvance/` — Therapy Copilot ★필수
- Therapy Copilot 메인 화면
- **비개발자(상담사)용 평가 화면** ← 이 장의 핵심 메시지를 뒷받침

### `08-robotics/` — Sim-to-Real ★필수
- **로보틱스 발표 PDF 자료 전체** ← 여기에 그대로 넣어주세요
- 실제 로봇 Peg-in-hole 작업 사진 또는 시뮬레이션 화면
- 성공률 0% → 95.5% 그래프 *(없으면 코드로 만들겠습니다)*

### `09-computer-vision/` — 생성형 AI 연구
- 직접 구현한 모델의 결과 이미지 (생성 결과, 탐지 결과 등)
- 어텐션 맵 시각화 또는 논문 구현 결과 비교

### `10-workflow/` — AI로 일하는 방식
- 문서 기반 워크스페이스 구조 캡처 (마크다운 문서 트리 등)
- AI 도구 연동 화면
