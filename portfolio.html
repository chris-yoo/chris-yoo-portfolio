데이터 기반 문제 해결 ① 강화학습 기반 로봇 제어

낯선 기술을 빠르게 익히고, 서비스 성패를 가르는 핵심 변수를 데이터로 판단했습니다
서울대학교 DYROS 연구실 · Sim-to-Real Gap 완화 (참여연구원 · 2026.07 ~ 2026.08)
기술 과제 · 현실에 적용되지 않는 AI

시뮬레이션에서는 완벽하게 성공한 강화학습(RL) 정책이, 가상과 실제의 미세한 환경 차이로 인해 실제 로봇에서는 실패하는 ‘Sim-to-Real Gap’ 문제를 해결해야 했습니다.

분석 · 데이터 기반 핵심 변수 도출

정밀 조립 작업(Peg-in-hole)의 실패 데이터를 분석한 결과, 오류 패턴이 무작위가 아님을 발견했습니다. 5가지 물리 변수를 개별 통제하며 실험한 결과, 질량 변수의 영향은 미미한 반면 쿨롱 마찰 계수가 0.15Nm에 도달할 때 성공률이 0%로 급감하는 현상을 데이터로 증명했습니다.

검증 · 핵심 변수에 집중한 Gap 완화

핵심적인 변수만을 타겟팅하여 Gap 완화 기법인 도메인 랜덤화(Domain Randomization)를 적용했고, 0%였던 태스크 성공률을 95%까지 끌어올렸습니다.

생성형 AI · 개인화(Personalization) 모델 연구
  • DDPM부터 Stable Diffusion, 최신 VAR(Vision Auto-Regressive) 모델까지 이미지 생성 모델의 발전 흐름을 분석하고 아키텍처를 직접 구현
  • 최신 VAR 모델에 Textual Inversion 기법을 적용하여, 최소한의 이미지 데이터만으로 특정 대상을 학습시키는 생성형 모델 개인화 연구 수행

AI 활용 — 서비스 기획의 실행력을 높이는 업무 프로세스

3명이 서비스 개발과 고객 인사이트 발굴을 함께 수행할 수 있도록 업무 방식을 재설계했습니다
문제 · 사업개발 인력의 한계

3명이 서비스 기획과 개발뿐 아니라 시장 조사, 고객 인사이트 발굴, 미팅과 후속 업무까지 동시에 수행해야 했습니다. 고객 대응이 늘어날수록 반복 업무가 중요한 판단 시간을 잠식했습니다.

해결 01 · 사업개발 워크플로우 자동화
  • 고객 정보와 제품 명세, 미팅 기록을 문서 기반 워크스페이스에 통합하고 AI가 필요한 맥락을 읽도록 구성
  • 시장 조사, 고객별 콜드메일 초안, 회의록 요약과 후속 일정 관리 등 반복 업무를 AI로 지원해 고객과 제품에 집중할 시간을 확보
해결 02 · 고객 요구와 내부 실행의 연결

고객 피드백으로 서비스 방향이 바뀔 때 발생하는 재작업을 줄이기 위해, 요구사항을 기능과 우선순위로 정리한 뒤 담당자와 합의하고 개발에 반영하는 프로세스를 만들었습니다.
